# 🎮 Rock Paper Scissors

A classic Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## 🚀 Features

- Play against the computer
- Random computer moves
- Live score tracking
- Win/Lose/Draw messages
- Responsive design
- Neon-themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
