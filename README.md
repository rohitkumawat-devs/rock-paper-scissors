# 🎮 Rock Paper Scissors

A simple Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## Features

- Play against the computer
- Live score tracking
- Win/Lose/Draw messages
- Responsive layout
- Modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
